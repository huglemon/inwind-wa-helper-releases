# 乘风WA助手 Android 发布仓库

本仓库只存放 Android 正式安装包与更新清单，不包含源码。

- 最新 APK：`https://github.com/huglemon/inwind-wa-helper-releases/releases/latest/download/inwind-wahhelper-android.apk`
- 更新清单：`https://github.com/huglemon/inwind-wa-helper-releases/releases/latest/download/latest.json`
- 应用内位置：设置 → 检查更新

`latest.json` 包含 versionCode、versionName、APK 地址与 SHA-256。应用只接受本仓库 HTTPS 地址，校验哈希后才交给系统安装器。
